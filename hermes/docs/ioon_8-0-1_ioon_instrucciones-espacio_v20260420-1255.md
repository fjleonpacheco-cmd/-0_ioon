## 3. Convención de nombres de archivo

Seguimos la convención unificada del chat **fjlp 1.2 organizacion-de-archivos**. Resumen operativo:

**Patrón:**
```
<proyecto>_<ruta>_<contenedor>_<tema>_v<AAAAMMDD>-<HHMM>.<ext>
```

**Reglas clave:**

- Todo en minúsculas, sin acentos ni espacios; palabras en kebab-case (`-`), bloques separados con `_`.
- `<proyecto>` = `ioon` para cualquier archivo de este espacio.
- `<ruta>` = ruta numérica con mínimo 3 números: `8-<subtema>-<índice>`. Si hay sub-subtema, crece a 4+: `8-<subtema>-<subsubtema>-<índice>`.
- El **último número** de la ruta = índice del archivo dentro de su carpeta contenedora.
- `<contenedor>` = nombre kebab de la carpeta inmediata (suele coincidir con el subtema / sub-subtema).
- `<tema>` = descripción kebab del contenido. Puede llevar sufijo de serie (`presentacion-3`).
- `v<AAAAMMDD>-<HHMM>` = versión con fecha y hora 24h. Cada guardado relevante = archivo nuevo; no se sobrescribe.

**Ejemplos en este espacio:**

- `ioon_8-1-1_esencia_manifiesto_v20260420-1300.md`
- `ioon_8-10-2_identidad-visual_paleta-color_v20260420-1310.pdf`
- `ioon_8-14-2-3_serclin_presentacion-3_v20260420-1230.pptx`
